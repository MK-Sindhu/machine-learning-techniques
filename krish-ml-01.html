At a glance

  • AI is the umbrella: applications that do a task without human intervention. Machine learning is the subset that uses statistical tools to analyze data and predict; deep learning is the subset of ML built on multi-layered neural networks. Data science draws on all three.
  • Supervised ML has a dependent (output) feature. A continuous output makes it regression; a fixed set of categories makes it classification. Unsupervised ML has no output and covers clustering and dimensionality reduction.
  • Linear regression fits the line \(h_\theta(x) = \theta_0 + \theta_1 x\) by minimizing the squared-error cost \(J(\theta_0,\theta_1) = \frac{1}{2m}\sum_i \big(h_\theta(x_i) - y_i\big)^2\).
  • The convergence algorithm (gradient descent) repeats \(\theta_j := \theta_j - \alpha\,\partial J/\partial\theta_j\). The sign of the slope sets the direction and the learning rate \(\alpha\) sets the step size. The squared-error cost has no local minima to get stuck in.
  • \(R^2 = 1 - SS_{\text{res}}/SS_{\text{tot}}\) measures the fit but never falls when a feature is added, even a useless one. Adjusted R² charges for each extra predictor, so it drops when a new feature does not help.

A supervised data set: age and weight

Take a data set with two columns, age and weight, with rows such as age 24 and weight 62. The task is to train a model on this data so that, given a new age, it returns a weight. A trained model of this kind is also called a hypothesis, a word that comes back with linear regression.

9:46

Independent and dependent features

Every supervised data set has two kinds of columns.

  • Independent features are the inputs the model is trained on. Here that is age.
  • The dependent feature is the output the model must predict. Here that is weight. It is called dependent because its value changes as the inputs increase or decrease.

A supervised problem has one dependent feature and any number of independent features.

10:50

Regression: the output is continuous

Keep the age and weight example. Weight is a continuous variable, and whenever the output is continuous the problem is a regression problem.

To solve it with linear regression, plot the data as a scatter plot and draw a straight line through it, \(y = mx + c\). For a new age, the point on the line above it is the predicted weight.

  • Two categories, such as pass and fail: binary classification.
  • More than two categories: multiclass classification.

Unsupervised learning: clustering and dimensionality reduction

In unsupervised ML there is no output variable and no dependent feature. The question becomes what can be learnt from the inputs alone.

Clustering and customer segmentation

Take a data set of customers' salary and age. Clustering finds groups of similar people. Krish sketches three clusters: young people who already earn a very good salary, older people with good salaries, and a middle-class group whose salary does not rise much with age. Each cluster says something about the people in it.

The use he gives is customer segmentation. Suppose a company launches one product for rich customers and another for middle-class customers. With the clusters in hand, it can send each product's ads only to the matching group. Regression or classification models can then be built on top of the segments.

Clustering is not classification. It is a grouping method, and there is no output feature to predict.

Dimensionality reduction

Dimensionality reduction takes data with many features, say 1000, and converts it to far fewer, say 100. PCA is one such algorithm, and he names LDA as another to cover later.

18:14

Linear regression: find the best fit line

Take two features, \(x\) (age) and \(y\) (weight), and a scatter of training points. Linear regression trains a model on this training data set. The model is a hypothesis: it takes a new age and returns a predicted weight. Performance metrics then check whether the model is doing well.

The model is a best fit line through the points, so \(y\) is treated as a linear function of \(x\). Why a straight line and not a curve is a question he leaves to the later algorithms.

20:01 21:34 intercept and slope

The hypothesis \(h_\theta(x) = \theta_0 + \theta_1 x\)

The same straight line goes by many notations: \(y = mx + c\), \(y = \beta_0 + \beta_1 x\), or \(h_\theta(x) = \theta_0 + \theta_1 x\). Krish uses the last one, which comes from Andrew Ng's course, and credits Ng for the way he teaches this algorithm.

\[ h_\theta(x_i) = \theta_0 + \theta_1 x_i \]
  • \(\theta_0\) is the intercept. At \(x = 0\), \(h_\theta(x) = \theta_0\), so it is the point where the line meets the y-axis.
  • \(\theta_1\) is the slope, also called the coefficient: how much the line moves along the y-axis for a one-unit move along the x-axis.
  • \(x_i\) are the data points.

The aim 23:11 is a line for which the distance between each actual point and its predicted point on the line is small, so that the sum of these distances is minimal. Only then can we call it the best fit line.

24:22 27:37 J(θ₀, θ₁)

The cost function

One way to find the best line would be to draw many lines and keep the one with the smallest total distance. There is no telling how many lines that takes, or how to know when the best one has been found. A better plan is to start from one line and move step by step toward the best one. That needs a cost function, one number that says how bad the current line is.

For each point, the gap between prediction and truth is \(h_\theta(x_i) - y_i\). Square it, add over all \(m\) points, and divide by \(2m\):

Cost function (squared error function) \[ J(\theta_0, \theta_1) = \frac{1}{2m}\sum_{i=1}^{m}\big(h_\theta(x_i) - y_i\big)^2 \qquad\text{Goal: } \min_{\theta_0,\,\theta_1} J(\theta_0, \theta_1) \]

Keep changing \(\theta_0\) and \(\theta_1\) until \(J\) is as small as it can be; that line is the best fit line.

Each piece of the formula has a reason 28:44.

  • The square stops negative errors from cancelling positive ones.
  • Dividing by \(m\) turns the sum into an average over the data points.
  • The extra \(\tfrac12\) is for mathematical convenience. The derivative of \(x^2\) is \(2x\) (in general, of \(x^n\) it is \(n x^{n-1}\)), so when \(\theta_0\) and \(\theta_1\) are updated using derivatives, the 2 cancels the \(\tfrac12\).

He calls the whole expression the squared error function.

Not in the video: without the \(\tfrac12\), \(J\) is the mean squared error (MSE). Scaling by \(\tfrac12\) changes the value of \(J\) but not which \(\theta_0, \theta_1\) minimize it. For the IIT Madras treatment, which writes the same objective as a plain sum of squared errors, see Part 10 (part-10.html).

30:52 32:00 three points 39:41 the curve

Worked example: try three slopes

To see the shape of \(J\), simplify first. Set \(\theta_0 = 0\), so the line passes through the origin and \(h_\theta(x) = \theta_1 x\). The cost now depends on \(\theta_1\) alone. The data are three points, \((1, 1)\), \((2, 2)\) and \((3, 3)\), so \(m = 3\) and \(\tfrac{1}{2m} = \tfrac16\).

  • \(\theta_1 = 1\). The line passes through all three points, so each predicted point is the data point itself and \(J(1) = 0\).
  • \(\theta_1 = 0.5\) 35:22. The line is flatter and every prediction falls short, so \(J(0.5) \approx 0.58\) (worked out below).
  • \(\theta_1 = 0\) 38:01. The line is the x-axis and \(J(0) = \tfrac16(1 + 4 + 9) \approx 2.33\).
\[ J(0.5) = \frac16\Big[(0.5-1)^2 + (1-2)^2 + (1.5-3)^2\Big] = \frac{0.25 + 1 + 2.25}{6} \approx 0.58 \]

Plot each \((\theta_1, J)\) pair, add a point for \(\theta_1 = 2\), and join them. The result is a U-shaped curve of the cost against \(\theta_1\). Its lowest point is the global minimum, at \(\theta_1 = 1\): the slope of the best fit line, where the predicted points are closest to the real ones.

A naming slip to watch for: in the video this U-shaped curve is itself called gradient descent. The curve is the cost function \(J(\theta_1)\). Gradient descent is the procedure that walks down it, described next.

Not in the video: for this data \(J(\theta_1) = \tfrac16(\theta_1 - 1)^2(1^2 + 2^2 + 3^2) = \tfrac73(\theta_1 - 1)^2\), an exact parabola. That is why \(\theta_1 = 0.5\) and \(1.5\) give the same cost, and so do \(0\) and \(2\).

41:22 42:57 why it works

The convergence algorithm

Trying values of \(\theta_1\) by hand is guesswork. What we want is to start from one point on the curve and keep updating \(\theta_1\) until it reaches the global minimum. The rule that does this is the convergence algorithm:

Convergence algorithm (gradient descent) \[ \text{repeat until convergence:}\qquad \theta_j := \theta_j - \alpha\,\frac{\partial}{\partial\theta_j}\, J(\theta_0, \theta_1) \]

\(:=\) means the left side is replaced by the right side. \(\alpha\) is the learning rate. The derivative is the slope of the cost curve at the current point.

On the board the derivative is read out the other way round, as the derivative of \(\theta_j\) with respect to \(J\). It is the derivative of \(J\) with respect to \(\theta_j\), as written above.

Why the update heads for the minimum

Draw the tangent to the cost curve at the current \(\theta_1\). Krish's quick test for its sign: if the right-hand end of the tangent points upward, the slope is positive.

  • Right of the minimum 44:00, the slope is positive. \(\theta_1 := \theta_1 - \alpha \times (\text{positive})\) makes \(\theta_1\) smaller, so it moves left, toward the minimum.
  • Left of the minimum 45:36, the slope is negative. Minus times minus is plus, so \(\theta_1 := \theta_1 + \alpha \times \lvert\text{slope}\rvert\) and \(\theta_1\) moves right, toward the minimum.

Either way, after enough iterations \(\theta_1\) reaches the global minimum.

46:20

The learning rate \(\alpha\)

The learning rate sets the speed at which \(\theta_1\) travels toward the global minimum, that is, the size of each step.

  • A small value takes small steps toward the minimum. This is the usual choice; he mentions values such as 0.1 as a starting point.
  • A very large value makes \(\theta_1\) jump from one side of the curve to the other, and it may never reach the global minimum.
  • A very, very small value takes tiny steps, so reaching the minimum takes forever and the model keeps on training.

Choose a small learning rate, but not so small that training never finishes.

Not in the video: where the limit of 0.43 comes from. For this data \(dJ/d\theta_1 = \tfrac{14}{3}(\theta_1 - 1)\), so one step turns the distance to the minimum, \(\theta_1 - 1\), into \((1 - \tfrac{14}{3}\alpha)(\theta_1 - 1)\). The distance shrinks only while \(\lvert 1 - \tfrac{14}{3}\alpha\rvert < 1\), that is \(0 < \alpha < \tfrac37 \approx 0.43\). For \(\alpha\) between \(\tfrac{3}{14} \approx 0.21\) and \(\tfrac37\) the factor is negative, so each step lands on the other side of the minimum, a little closer each time.

47:12 48:18 deep learning

What about local minima?

Suppose the cost curve had a dip that is not its lowest point, a local minimum. The slope there is zero, so the update reads \(\theta_1 := \theta_1 - \alpha \times 0 = \theta_1\) and \(\theta_1\) stops changing. Gradient descent would be stuck, as in the right panel of the figure above.

This does not happen in linear regression. With the squared-error cost the curve always has the single-bowl shape of the worked example, so its only minimum is the global one. Deep learning is different. The cost of an artificial neural network (ANN) has many local minima, and that is one reason optimizers such as RMSprop and Adam exist.

Interview answer: linear regression's cost function has no local minima. Local minima are a deep learning problem, handled by optimizers such as RMSprop and Adam.

When does convergence stop 49:24? When \(\theta\) reaches the region near the bottom, where \(J\) is very small.

Not in the video: in practice the loop stops once \(J\) changes by less than a small tolerance between iterations, or after a fixed number of iterations. The squared-error cost is convex, which is the formal reason it has no minimum other than the global one. For the IIT Madras treatment, see Part 10 (part-10.html).

50:28 53:44 final updates

Gradient descent for \(\theta_0\) and \(\theta_1\)

Now bring \(\theta_0\) back. The same rule applies to each parameter, \(j = 0\) and \(j = 1\), so what remains is to work out the two derivatives of

\[ J(\theta_0, \theta_1) = \frac{1}{2m}\sum_{i=1}^{m}\big(\theta_0 + \theta_1 x_i - y_i\big)^2 \]

Differentiate the square: the power 2 comes down and cancels the \(\tfrac12\). Then multiply by the derivative of what is inside the bracket. With respect to \(\theta_0\) that inner derivative is 1. With respect to \(\theta_1\) it is \(x_i\), because \(\theta_1 x_i\) is the only term that contains \(\theta_1\).

\[ \frac{\partial J}{\partial\theta_0} = \frac1m\sum_{i=1}^{m}\big(h_\theta(x_i) - y_i\big), \qquad \frac{\partial J}{\partial\theta_1} = \frac1m\sum_{i=1}^{m}\big(h_\theta(x_i) - y_i\big)\,x_i \]

The square is gone from both. (On the board it is first left in and then corrected.)

  1. Gradient descent for linear regression with one feature
  2. Pick a learning rate \(\alpha\), for example 0.1, and starting values for \(\theta_0\) and \(\theta_1\).
  3. Compute every prediction \(h_\theta(x_i) = \theta_0 + \theta_1 x_i\) and its error \(h_\theta(x_i) - y_i\).
  4. Update \(\theta_0 := \theta_0 - \alpha\,\frac1m\sum_{i=1}^m \big(h_\theta(x_i) - y_i\big)\).
  5. Update \(\theta_1 := \theta_1 - \alpha\,\frac1m\sum_{i=1}^m \big(h_\theta(x_i) - y_i\big)\,x_i\).
  6. Repeat from step 2 until convergence, when \(J\) stops falling.

Not in the video: both updates should use the errors computed from the old \(\theta_0\) and \(\theta_1\) (a simultaneous update). Updating \(\theta_0\) first and then using the new value inside the \(\theta_1\) update is a common bug.

With several features \(x_1, x_2, x_3, x_4, \dots\) 54:51, the cost depends on more parameters. Krish pictures it as a 3-D bowl, and gradient descent as coming down a mountain to its lowest point. Strictly, \(J(\theta_0, \theta_1)\) with a single feature is already a 3-D bowl over the \((\theta_0, \theta_1)\) plane; each extra feature adds a dimension, and the bowl stays convex.

For the IIT Madras treatment, with the vector form \(\mathbf{w}_{t+1} = \mathbf{w}_t - \eta_t\nabla f(\mathbf{w}_t)\) and stochastic gradient descent, see Part 10 (part-10.html). The code version of this algorithm is in Part 3.

55:57 58:38 negative R²

R²: how good is the fit?

With a fitted line in hand, a performance metric checks how good the model is. For linear regression he discusses two, R² and adjusted R².

R² (R squared) \[ R^2 = 1 - \frac{SS_{\text{res}}}{SS_{\text{tot}}} = 1 - \frac{\sum_i \big(y_i - \hat y_i\big)^2}{\sum_i \big(y_i - \bar y\big)^2} \]

\(\hat y_i = h_\theta(x_i)\) is the prediction for point \(i\) and \(\bar y\) is the mean of \(y\).

  • \(SS_{\text{res}}\), the sum of squared residuals, adds the squared vertical distances from each point to its predicted point on the best fit line.
  • \(SS_{\text{tot}}\), the total sum of squares, adds the squared distances from each point to the horizontal line at the mean \(\bar y\).

For a good line the residuals are much smaller than the distances to the mean line. The fraction is then a small number, and 1 minus a small number is close to 1, say 90%. A large R² means the line fits well.

Can R² be negative?

Yes, if the line is worse than predicting the mean everywhere. Then \(SS_{\text{res}} > SS_{\text{tot}}\), the fraction exceeds 1, and R² drops below zero. In practice this does not happen with a sensibly fitted line, since nobody wants a best fit line that does worse than the mean line.

Not in the video: for a least-squares line with an intercept, evaluated on its own training data, \(SS_{\text{res}} \le SS_{\text{tot}}\) always holds, so R² lies between 0 and 1. Negative values show up on new data, or for a line that was not fitted by least squares.

59:38 1:01:51 the formula

Adjusted R²

R² has a weakness that shows when features are added. Krish's example predicts the price of a house.

Features usedRelated to price?R²Adjusted R²
bedroomsyes85%–
bedrooms, locationyes90%86%
bedrooms, location, gender of the occupantno91%82%

Location is correlated with price, so adding it raises R² from 85% to 90%. Whether a man or a woman will live in the house has nothing to do with its price, yet R² still rises, to 91%. The way R² is computed, adding a feature never lowers it, even when the feature is not correlated with the target at all. Choosing models by R² would then pick the three-feature model because of a meaningless feature.

Adjusted R² \[ R^2_{\text{adj}} = 1 - \frac{\big(1 - R^2\big)\,(N - 1)}{N - P - 1} \]

\(N\) is the number of data points and \(P\) the number of features (predictors).

The penalty works through \(P\). As \(P\) grows, the denominator \(N - P - 1\) shrinks, so the factor \(\frac{N-1}{N-P-1}\) that multiplies \(1 - R^2\) grows. Unless the new feature raises R² enough to make up for it, adjusted R² falls. A feature strongly correlated with the target raises R² a lot, and adjusted R² goes up as well. A useless one raises R² only a little, and adjusted R² goes down.

The adjusted values in the table (86% and 82%) are numbers he picks to show the direction. A consistent version: with \(N = 8\) houses, \(R^2 = 0.90\) and \(P = 2\) give \(1 - 0.10 \times \tfrac75 = 0.86\), while \(R^2 = 0.91\) and \(P = 3\) give \(1 - 0.09 \times \tfrac74 \approx 0.84\). Adjusted R² drops, so the two-feature model wins.

Adjusted R² is never larger than R². One of his students was asked in an interview which of the two is always bigger (R²), and then to explain adjusted R².

Key terms

AI ⊃ ML ⊃ DL
AI: applications that act without human intervention. ML: statistical tools to analyze and predict. DL: multi-layered neural networks that mimic the brain.
Data science
Solving a business problem with whichever of analysis, ML or DL it needs; it overlaps all three.
Supervised learning
Learning from data with a dependent (output) feature: regression or classification.
Unsupervised learning
Learning from data with no output feature: clustering (grouping) or dimensionality reduction.
Independent and dependent features
Inputs the model is trained on, and the one output it predicts.
Regression vs classification
Continuous output vs a fixed set of categories (binary for two, multiclass for more).
Hypothesis \(h_\theta(x)\)
The model; for linear regression the line \(\theta_0 + \theta_1 x\).
Intercept and slope
\(\theta_0\): where the line meets the y-axis. \(\theta_1\): change in \(y\) per unit change in \(x\).
Cost function \(J\)
Squared error function \(\frac{1}{2m}\sum (h_\theta(x_i) - y_i)^2\), minimized over \(\theta_0, \theta_1\).
Convergence algorithm
Gradient descent: repeat \(\theta_j := \theta_j - \alpha\,\partial J/\partial\theta_j\) until \(J\) stops falling.
Learning rate \(\alpha\)
Step size of each update; too large overshoots, too small takes forever.
Global and local minimum
The lowest point of the cost, and a dip that is lowest only nearby. Linear regression's cost has only the global one.
R²
\(1 - SS_{\text{res}}/SS_{\text{tot}}\): how much better the line is than the mean line. Never falls when a feature is added.
Adjusted R²
\(1 - (1 - R^2)(N-1)/(N-P-1)\): R² with a charge per predictor; drops when a useless feature is added.

Test yourself

Q1Name the problem type: (a) predict a flat's rent in rupees; (b) predict whether a loan will default; (c) group shoppers by spending with no labels; (d) predict which of five genres a song belongs to.

(a) Regression, since rent is continuous. (b) Binary classification, two categories. (c) Clustering, an unsupervised problem with no dependent feature. (d) Multiclass classification, more than two categories.

Q2For the points \((1,1)\), \((2,2)\), \((3,3)\) with \(\theta_0 = 0\), compute \(J(1.5)\).

Predictions 1.5, 3, 4.5; errors 0.5, 1, 1.5; squares 0.25, 1, 2.25. So \(J(1.5) = 3.5/6 \approx 0.58\), the same as \(J(0.5)\), because the cost curve is symmetric about \(\theta_1 = 1\).

Q3Why does the cost function square the errors, divide by \(m\), and carry an extra \(\tfrac12\)?

Squaring stops positive and negative errors from cancelling. Dividing by \(m\) gives an average. The \(\tfrac12\) cancels the 2 that appears when the square is differentiated, which keeps the update rules clean; it does not change which \(\theta\) minimizes \(J\).

Q4Same three points, \(\theta_0 = 0\). Start at \(\theta_1 = 2\) with \(\alpha = 0.1\). What is the slope, and what is \(\theta_1\) after one step?

\(dJ/d\theta_1 = \frac13\sum(2x_i - x_i)\,x_i = \frac13(1 + 4 + 9) = \frac{14}{3} \approx 4.67\), positive. So \(\theta_1 := 2 - 0.1 \times 4.67 \approx 1.53\). It moved left, toward 1, and \(J\) fell from 2.33 to about \(\tfrac73(0.53)^2 \approx 0.66\).

Q5What goes wrong if the learning rate is too large? Too small?

Too large: each update jumps over the minimum to the other side of the curve, possibly further out each time, so it may never reach the global minimum. Too small: the steps are tiny and convergence takes a very long time.

Q6Why does the \(\theta_1\) update contain \(x_i\) while the \(\theta_0\) update does not?

By the chain rule, the derivative of \((\theta_0 + \theta_1 x_i - y_i)^2\) is \(2(\theta_0 + \theta_1 x_i - y_i)\) times the derivative of the bracket. That inner derivative is 1 with respect to \(\theta_0\) and \(x_i\) with respect to \(\theta_1\).

Q7An interviewer asks whether gradient descent for linear regression can get stuck in a local minimum. What do you say?

No. The squared-error cost is a single convex bowl, so its only minimum is the global one. Local minima are a problem in deep learning (ANNs), where optimizers such as RMSprop and Adam help.

Q8With \(N = 8\) points, a 2-predictor model has \(R^2 = 0.90\). Adding an unrelated third predictor gives \(R^2 = 0.91\). Compute both adjusted R² values. Which model do you keep?

\(P = 2\): \(1 - 0.10 \times 7/5 = 0.86\). \(P = 3\): \(1 - 0.09 \times 7/4 \approx 0.84\). Adjusted R² fell, so keep the 2-predictor model; the small R² gain does not pay for the extra predictor.
